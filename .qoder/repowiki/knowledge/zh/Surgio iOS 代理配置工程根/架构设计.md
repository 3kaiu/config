根目录作为 Surgio 工程的编排中心：surgio.conf.js 声明 provider（tokyo 单节点）、remoteSnippets（blackmatrix7 规则源）、customFilters/customParams（DNS/DoH/DoQ 变量）与三套 artifacts（Loon.lcf / QX.conf / Surge.conf），由 package.json 的 scripts 驱动 generate/preview/test/lint 命令；templates/ 下的 Jinja2 模板按 provider 与 customParams 渲染最终 Profile，并引用 plugin_rules/、scripts/、qx_apple/ 等子模块作为运行时片段；mirror_scripts/ 集中缓存第三方脚本并输出 ENGINE-MANIFEST.json 供 CI 校验；ci_workflows/ 串联 surgio-build、config-validate、upstream-health、cdn-verify、pages-deploy 等工作流形成完整流水线；tests/ 通过 Node vm 沙箱对 Scripts 回归测试；docs/ 记录审计与迁移文档。所有子模块通过 Surgio 的 template/snippet/provider 契约解耦，Profile/ 为唯一产物目录。
