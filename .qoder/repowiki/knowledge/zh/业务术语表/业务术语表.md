### MitM
- 定义：中间人攻击（Man-in-the-Middle）解密技术，在本项目中指对特定域名进行 TLS 证书安装和流量解密，用于实现广告拦截、响应修改等功能。采用严格的白名单机制，仅对起点读书、智慧房东等必要域名启用，银行域名通过负向排除确保不被解密。
- 别名：MITM、HTTPS解密、证书安装

### REJECT
- 定义：DNS 级别的请求拒绝策略，在解析阶段直接返回空结果或错误，用于阻止广告、追踪、HTTPDNS 等不需要解密的恶意请求。相比 MitM 更安全且性能更好，是本项目首选的去广告实现方式。
- 别名：DNS拒绝、REJECT规则

### 策略组
- 定义：代理路由的策略分组，将不同类别的流量（Streaming/AI/Developer/Social/Final）分配到不同的代理节点。支持 url-test 自动选优、手动切换、延迟检测等功能，单节点场景下主要用于故障时的显式报错而非静默回落。
- 别名：Proxy组、Rule组、策略分组

### Snippet
- 定义：可复用的配置片段，用于在 Loon 和 Quantumult X 双端之间共享相同的域名规则和路由逻辑。每个业务领域（流媒体、社交、AI服务等）都有对应的 .tpl 和 .qx 两个版本的 snippet 文件，确保双端配置一致性。
- 别名：片段、模板片段、snippet

### Plugin
- 定义：Loon 专用的插件文件格式，包含元信息（#!name/#!version/#!desc）、Script 规则、Rule 规则、MitM 配置等。每个 Plugin 对应一个特定的 App 或功能，如 qidian.plugin、bank.plugin 等，通过 script-path 引用外部 JavaScript 脚本。
- 别名：插件、Loon插件、.plugin

### Provider
- 定义：Surgio 中的节点提供者定义，负责从外部订阅源获取代理节点列表。本项目使用 tokyo.js 定义东京单节点 provider，支持通过环境变量 SURGIO_SUBSCRIPTION_URL 注入 shadowsocks 订阅格式。
- 别名：节点提供者、provider

### HTTPDNS
- 定义：通过 HTTP 协议进行 DNS 解析的技术，常用于绕过运营商 DNS 污染。本项目通过三层防御机制拦截：正则重写拦截、DOMAIN-KEYWORD 通杀、Host 静态映射，防止 App 绕过系统 DNS 导致的安全问题。
- 别名：HTTPDNS拦截、HTTPDNS过滤

### DoH/DoQ/DoH3
- 定义：加密 DNS 协议，包括 DNS over HTTPS (DoH)、DNS over QUIC (DoQ)、DNS over HTTPS 3 (DoH3)。本项目配置了阿里、腾讯、火山引擎等多家加密 DNS 服务器，提升解析安全性和速度，同时防止 DNS 泄露。
- 别名：加密DNS、DoH、DoQ、DoH3

### Fake-IP
- 定义：虚拟 IP 技术，将域名解析到私有网段（如 198.18.0.0/16），用于加速连接建立和隐藏真实 IP。但可能导致游戏主机联机、Apple 服务等异常，需要通过 dns_exclusion_list 排除相关域名。
- 别名：虚拟IP、FakeIP

### Cron
- 定义：定时任务调度机制，用于执行周期性任务如自动签到、健康检测、流量统计等。Loon 和 Quantumult X 都支持 cron 表达式，本项目通过 Plugin 的 [Script] 段和 task_local 配置实现定时任务。
- 别名：定时任务、cron任务、计划任务

### Sub-Store
- 定义：订阅管理工具，用于管理和转换各种代理订阅格式。本项目从停更的 ajune0527/vpn_tool 迁移到自维护的 sub-store.plugin，支持 Sub-Store 集合的节点管理和格式转换。
- 别名：订阅管理、SubStore

### Engine Manifest
- 定义：引擎完整性清单文件（ENGINE-MANIFEST.json），用于记录和校验嵌入在脚本中的第三方引擎代码。包含 SHA256 哈希、上游提交信息、更新流程等，确保嵌入代码未被篡改。
- 别名：引擎清单、ENGINE-MANIFEST
