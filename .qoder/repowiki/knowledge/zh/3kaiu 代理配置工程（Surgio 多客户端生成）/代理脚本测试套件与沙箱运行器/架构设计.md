模块由三层构成：
- 入口 `run-tests.js`：扫描 `test/cases/*.test.js`，按约定加载每个文件导出的 `{ tests: { name: async fn(assert, harness) } }`，逐个执行并统计通过/失败数。
- 断言与收集器 `makeAssert()`：提供 `equal`、`ok`、`includes`、`notIncludes` 四个方法，将断言失败收集到 `fails` 数组，统一在测试结束后抛出。
- 沙箱 `harness.js`：使用 Node `vm` 创建隔离上下文，注入 `console`、Promise/URL/JSON 等 JS 内建、`$done`、以及按 `mode`（`loon`/`qx`）注入 `$httpClient/$persistentStore/$notification` 或 `$task/$prefs/$notify`；`runScript` 将目标脚本包裹为 async IIFE 执行，并冲刷微任务后返回 `state`（含 `doneCalls`、`notifications`、`httpCalls`、`store`、`logs`）供用例断言。
- 用例位于 `cases/` 下，每个 `.test.js` 文件针对一组相关脚本编写多个异步测试，通过 `h.createSandbox` 构造请求/响应环境并调用 `h.runScript` 驱动被测脚本。
