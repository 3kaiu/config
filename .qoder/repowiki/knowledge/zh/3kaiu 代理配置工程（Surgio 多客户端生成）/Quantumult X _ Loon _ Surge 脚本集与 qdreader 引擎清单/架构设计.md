本模块由两类独立脚本组成：
- 站点去广告脚本（Amap.js、JD.js、Cainiao.js、Qidian.js、Reddit.js、Tieba.js、Zhihu.js、Zhihuifangdong.js）：每个文件是一个自包含的响应拦截器，通过检测 $response 守卫避免被全局 MitM 误触 request 阶段，解析 JSON 后清空 data 字段再 $done() 返回。
- 通知类脚本（health-notify.js、traffic-notify.js）：通过 $httpClient 探测网络连通性或读取 $environment 信息，统一经 Bark/Telegram 推送，并在结束时 await 完成后再调用 $done() 防止上下文回收中断请求。
- 所有脚本通过 `typeof $task !== 'undefined'` 区分 QX 与 Loon/Surge，使用兼容层 `_read`/`_notify` 分别调用 `$prefs.valueForKey`/$persistentStore 和 `$notify`/$notification.post。
- Qidian.js 内嵌经过 base64+RC4+javascript-obfuscator 三层混淆的 qdreader 引擎，其上游版本、嵌入时间、sha256 摘要与 RC4 key 均记录在 ENGINE-MANIFEST.json 中，供 CI 校验与更新流程使用。
