- 每个业务领域在 `snippet/` 下成对提供 `.tpl`（Loon/Surge 用 DOMAIN-* 语法）和 `.qx`（QX 用 host-* 语法）两个同名文件，保持语义一致但语法适配各自客户端。
- 模板中使用 Jinja2 的 `{{ customParams.* }}` 占位符注入 DNS、订阅等可配置参数，条件分支通过 `{% if customParams.xxx %}...{% endif %}` 控制可选功能。
- 规则按「银行白名单 → STUN 阻断 → 局域网 → HTTPDNS 拦截 → Apple/微信 → 各业务 snippet → Google 通配域名 → 分析/广告 REJECT → GEOIP/FINAL」固定顺序组织，确保匹配优先级正确。
- 远程规则集统一通过 `https://ws.wenn.in/main/Mirror/rules/` 前缀引用，并附带 `tag=` 中文标签与 `enabled=true` 开关。
- MITM 配置中大量使用 `-*.domain` 负向排除语法（Loon/QX）或显式白名单（Surge），以规避银行/支付类域名的证书校验冲突。
