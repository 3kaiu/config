本模块按客户端类型与用途两个维度组织：
- 客户端前缀区分：`loon-*` 文件面向 Loon，`qx-*` 文件面向 Quantumult X。
- 规则文件分类：`.list` 为纯分流/重写规则（如 Advertising、China、Global、Hijacking、Privacy），`.plugin` 为 Loon 的聚合插件（AllInOne 汇总多类规则），`.conf` 为 ddgksf2013 贡献的特定 App 去广告重写规则（WeChat、NeteaseAds、BiliBiliComicsAds 等）。
- 工具脚本：`resource-parser.js` 是 KOP-XIAO 的资源解析器，支持 V2Ray/SS/VMess/Trojan/QuantumultX/Surge/Clash/Shadowrocket/Loon 等多格式订阅转换；`loon-sub-store-parser.js` 为 Loon Sub Store 解析器；`geo-location.js`、`ip-api.js` 用于 IP 地理位置查询；`streaming-ui-check.js`、`traffic-check.js` 分别实现流媒体解锁检测与策略流量统计。
- 依赖方向：所有 `.list`/`.conf` 均为静态数据，被上层配置文件引用；JS 脚本通过 `$environment`、`$configuration.sendMessage`、`$done` 等 Quantumult X/Loon 运行时 API 与客户端交互，不互相依赖。
