- 每个脚本顶部以 JSDoc 注释标明版本号、作者、覆盖范围及修复历史，便于追踪变更来源。
- 通过 `typeof $response === 'undefined'` 守卫在 request 阶段直接 `$done()` 返回，避免被全局 MitM 规则误触发。
- QX 与 Loon/Surge 的差异通过 `isQX = typeof $task !== 'undefined'` 判断，并以 _read/_notify 等兼容函数封装差异调用。
- 远程推送（Bark/Telegram）统一包装为 Promise，并在脚本末尾用 `Promise.resolve(push).then(() => $done())` 等待完成，防止上下文回收中断请求。
- JSON 响应处理包裹 try/catch，解析失败时兜底调用 `$done()` 保证脚本不崩溃。
